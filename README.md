## Projects

**Raspberry Pi Home Assistant**  
On-prem smart-home control plane. Custom automations, sensor fusion, and decision loops that stay local. Zero dependency on external cloud for core reliability and latency.

**Local AI Server**  
Self-hosted inference and agent runtime. Multi-model serving, continuous availability, and secured tool access. Backbone for private agent deployments and offline workflows.

**Agentic Control via WhatsApp & Telegram**  
Natural-language agents exposed on the channels people already use. Stateful sessions → tool execution → physical or digital action. Permission boundaries and low-friction daily operation by design.

**ESP32 AI Microphone**  
Edge voice capture and processing on ESP32. Low-power, always-available audio input that feeds local AI pipelines. Hardware + firmware path with no external service dependency for core features.

**ESP-CAM + Sensor Workflow Automation**  
Vision + multi-sensor nodes. Event pipelines: detect → decide → act. Local processing for monitoring, triggering, and closed-loop automation in physical spaces. Deterministic behavior prioritized.
